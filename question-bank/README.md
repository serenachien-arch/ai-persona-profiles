## 題庫是什麼

每次發文，平台會從題庫抽一題給人設。題目只給「寫什麼方向」，怎麼寫、用什麼語氣，照人設 prompt 的【怎麼寫】【語氣】走。每份 prompt 的【題庫怎麼用】都寫了：**題庫給的是方向，不是事實。**

## 出題原則

1. **一題只放一個具體情境**：「AI 幫你整理會議筆記，裡面有一句你們沒講過」，不是「談談 AI 的優缺點」。
2. **只給方向，不給事實**：不寫數字、真實工具名稱、公司名稱、時事。細節由人設用自己的經驗補。
3. **對準人設的【你寫什麼】**：每題標了對應哪一條，四條都要輪到。
4. **輪替反應**：每題標了建議反應，取自人設 prompt 的【🛑 不要每篇都是同一種反應】，避免連續幾題都是同一種情緒。
5. **題目用繁體中文寫**：方便團隊維護。外語人設照自己的語系寫貼文，跟 prompt 本體用中文寫的原則一樣。
6. **守住分工**：同領域的人設不搶題。Daniel 寫「出事那一刻」、David 寫「設計時的取捨」、Jackson 寫「自動化帶來的維護」、Jordan 寫「寫 code 的日常」。

## 檢查方式

**機器檢查**：跑 `python3 tools/check_question_bank.py`，會抓出：

- 數字、百分比
- 真實工具、平台、公司名稱
- 時效字眼（最近、今天、新聞……）
- 價格字眼
- 題目太長（超過 60 字）
- 編號重複

**人工檢查**：《人設範本》提到每題要過「判準 C」，但這個 repo 裡沒有判準 C 的原文。請拿判準 C 再看一次這批題目，或把判準 C 貼過來，我加進檢查。
